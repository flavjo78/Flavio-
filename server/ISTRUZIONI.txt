PREDIZIONE — come mettere online il sistema (hosting PHP, es. Tophost / Aruba)
============================================================================

COSA TI SERVE
- Un dominio + spazio hosting con PHP (Tophost "Topweb" va benissimo).
- Un programma per caricare i file (il "Gestione File" del pannello,
  oppure un programma FTP come FileZilla).


I FILE DEL SERVER (cartella "server/" del progetto)
- config.php   -> impostazioni (qui dentro scegli la TUA PASSWORD)
- image.php    -> l'immagine dinamica che finisce nella mail
- stato.php    -> riceve i comandi Avvia/Finisci dal pannello
- carica.php   -> riceve le foto dal pannello
Le foto, lo stato del gioco e il log NON si caricano a mano: li gestisce
il pannello da solo, e finiscono nella cartella protetta _dati/ (creata
in automatico).


PASSO 1 — Scegli la password
- Apri config.php e cambia questa riga:
      const PREDIZIONE_PASSWORD = 'CAMBIA_QUESTA_PASSWORD';
  mettendo una password tua, difficile da indovinare. La stessa password
  la userai nel pannello. NON condividerla con nessuno.


PASSO 2 — Carica i file
- Crea sul server una cartella, per esempio:   /predizione/
- Dentro carica QUESTI quattro file:
      config.php , image.php , stato.php , carica.php
- Non serve creare tu la cartella _dati/: la crea da sola al primo utilizzo.


PASSO 3 — Prova che il server risponda
- Apri nel browser:
      https://abraka.it/predizione/image.php
  A gioco spento deve comparire (o sembrare vuoto): e' un'immagine neutra
  trasparente. E' normale: la foto vera appare solo quando il pannello
  avvia il gioco.
- Poi apri il pannello, inserisci la password, carica le due foto e premi
  "Avvia gioco": ricaricando image.php dovrai vedere la Foto A. Premendo
  "Finisci gioco" (o allo scattare dell'orario di sicurezza) vedrai la B.


PASSO 4 — Metti l'immagine nella mail
- Nel corpo della mail (in HTML) inserisci questa immagine:

      <img src="https://abraka.it/predizione/image.php?s=NUMEROSESSIONE&id=SPETTATORE1"
           width="500" style="display:block;max-width:100%;border:0" alt="">

- ?s=NUMEROSESSIONE  e' il numero della sessione in corso (lo mostra il pannello,
  es. "Sessione #1"). E' IMPORTANTE: lega quella mail alla sua sessione, cosi'
  chi la riceve continuera' a vedere sempre la rivelazione di QUELLA sessione.
- ?id=SPETTATORE1  da' un indirizzo diverso a ogni spettatore (aiuta contro la
  cache) e fa sapere chi apre. Metti un id diverso per ognuno.
- In futuro sara' l'autorisponditore a riempire s e id in automatico.


COME FUNZIONA LO SCAMBIO (le tre fasi + le sessioni)
- SPENTO     -> image.php mostra un'immagine neutra; le mail non vanno elaborate.
- IN CORSO   -> dopo "Avvia gioco": chi apre vede la Foto A (neutra di attesa).
- TERMINATO  -> dopo "Finisci gioco" OPPURE allo scattare dell'orario di
               sicurezza: chi apre vede la RIVELAZIONE di quella sessione.

LE SESSIONI (importante)
- Ogni "Avvia" apre una NUOVA sessione con: la Foto A neutra (sempre la stessa,
  finche' non la cambi) + la rivelazione che hai caricato per quella sessione.
- Ogni sessione conserva le SUE foto. Se domani avvii un'altra sessione con una
  rivelazione diversa, chi era nella sessione di ieri continua a vedere la SUA.
- Per questo l'indirizzo dell'immagine deve avere ?s=NUMEROSESSIONE.


IL LOG DELLE APERTURE (la "cattura")
- Ogni apertura viene registrata nel file  _dati/aperture.csv
- Contiene: data e ora, numero sessione, id spettatore, foto mostrata, IP, dispositivo.
- Per disattivarlo: in config.php metti  const ABILITA_LOG = false;


IMPORTANTISSIMO — NON spegnere mai il server / non cancellare la cartella:
la foto resta visibile agli spettatori solo finche' questi file restano online.
