PREDIZIONE — come mettere online l'immagine dinamica (hosting PHP, es. Aruba)
============================================================================

COSA TI SERVE
- Un dominio + spazio hosting con PHP (Aruba va benissimo).
- Le due foto pronte.
- Un programma per caricare i file (il "Gestione File" del pannello Aruba,
  oppure un programma FTP come FileZilla).


PASSO 1 — Prepara i file
- Rinomina le due foto:
    foto_a.jpg  = quella che si vede PRIMA dell'orario
    foto_b.jpg  = quella che si vede DOPO l'orario
  (Se sono .png chiamale foto_a.png / foto_b.png e cambia i nomi dentro image.php.)


PASSO 2 — Carica tutto
- Crea sul server una cartella, per esempio:   /predizione/
- Dentro carica:   image.php ,  foto_a.jpg ,  foto_b.jpg


PASSO 3 — Imposta data e ora dello scambio
- Apri image.php e modifica la riga:
      $ORARIO_SCAMBIO = '2026-09-27 21:00:00';
  mettendo la data e l'ora del tuo show (formato: ANNO-MESE-GIORNO ORA:MIN:SEC).


PASSO 4 — Prova
- Apri nel browser:
      https://ILTUODOMINIO/predizione/image.php
  Prima dell'orario deve comparire la Foto A, dopo la Foto B.
- Per provare subito lo scambio senza aspettare: crea un file  forza.txt
  nella stessa cartella scrivendoci dentro solo  A  (o  B ). Ricarica la pagina:
  vedrai quella foto. Cancella forza.txt per tornare all'automatico a orario.


PASSO 5 — Metti l'immagine nella mail
- Nel corpo della mail (in HTML) inserisci questa immagine:

      <img src="https://ILTUODOMINIO/predizione/image.php?id=SPETTATORE1"
           width="500" style="display:block;max-width:100%;border:0" alt="">

- Il pezzo  ?id=SPETTATORE1  serve a due cose: dare un indirizzo diverso a ogni
  spettatore (aiuta contro la cache) e sapere chi apre. Metti un id diverso per
  ognuno (es. l'email o un numero progressivo).


IL LOG DELLE APERTURE (la "cattura")
- Ogni apertura viene registrata nel file  aperture.csv  nella stessa cartella.
- Contiene: data e ora, id spettatore, foto mostrata (A/B), IP, dispositivo.
- Lo apri con Excel o col Gestione File per vedere chi ha aperto e quando.
- Per disattivarlo: in image.php metti  $ABILITA_LOG = false;


IMPORTANTISSIMO — NON spegnere mai il server / non cancellare la cartella:
la foto resta visibile agli spettatori solo finche' questi file restano online.
